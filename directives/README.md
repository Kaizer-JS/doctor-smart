# Diretrizes (Directives - Camada 1)

Esta pasta armazena os Procedimentos Operacionais Padrão (SOPs) em formato Markdown.

Cada diretriz deve especificar:
- **Objetivo**: O que a tarefa realiza.
- **Entradas**: Parâmetros, arquivos ou dados necessários.
- **Ferramentas de Execução**: Scripts em `execution/` a serem utilizados.
- **Saídas**: Onde os resultados são salvos / exportados.
- **Tratamento de Exceções & Casos de Borda**: Limites de taxa, re-tentativas e regras específicas.
